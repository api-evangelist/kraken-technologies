# Kraken Technologies

> Kraken Technologies is the UK energy-technology company behind Kraken, the licensed cloud operating system for utilities. Spun out of Octopus Energy, it says it supports more than 90 million customer accounts for licensees including E.ON Next, EDF, Origin, Tokyo Gas, National Grid, Good Energy, Plenitude, Energy Queensland, Essential Energy, Portsmouth Water and TalkTalk, across electricity, gas, water and broadband. Its integration layer, Open Kraken, is real but closed: APIs, events, Embedded Apps, Flow automation and an announced MCP-based AI access layer are all licensee-only. No base URL, endpoint list, OpenAPI, AsyncAPI or GraphQL schema is published anywhere on the public web, and docs.kraken.tech returns an SSO login page for every path — including /openapi.json, /llms.txt and /.well-known/openid-configuration.

Generated by API Evangelist (apievangelist.com) from the public Kraken Technologies surface on 2026-07-27. Kraken publishes no llms.txt of its own (/llms.txt returns 404 on www.kraken.tech and the login page on docs.kraken.tech).

Homonym warning: "Kraken" also names the Kraken cryptocurrency exchange (kraken.com) and the KrakenD API gateway (krakend.io). Neither is this company. Everything below is on kraken.tech or a GitHub org whose declared website is kraken.tech.

## APIs

- [Open Kraken APIs and Events](https://www.kraken.tech/open-kraken): The integration layer of the Kraken utility operating system — "APIs, events and MCP", plus Flow automation and Embedded Apps. No base URL, endpoint list, authentication scheme or machine-readable contract is published. Access requires a Kraken licence.
- [Open Kraken AI Access Layer (MCP)](https://www.kraken.tech/open-kraken): Announced MCP gateways that let a utility's own AI agents orchestrate approved actions across Kraken, with fair use included; "gradually released". No server URL, tool list, scope model or transport is published; mcp.kraken.tech does not resolve.

## Docs

- [Kraken Docs](https://docs.kraken.tech/): Reference documentation. SSO-gated at every path; credentials are issued to licensees and contracted partners.
- [Open Kraken](https://www.kraken.tech/open-kraken): Public description of Flow, Embedded Apps, APIs/events and the AI access layer.
- [Kraken example apps](https://github.com/kraken-tech/kraken-apps-examples): The most substantive public developer documentation Kraken publishes — the Embedded Apps initialisation contract, the Kraken App Store Proxy headers, and the app JWT/JWKS model.
- [Tako Design System](https://tako.kraken.tech/): Public documentation for Kraken's component libraries.
- [Tako React Storybook](https://tako-react-kraken-tech.vercel.app/?path=/docs/components): 50 component families, public.
- [Tako HTML Storybook](https://tako-html-kraken-tech.vercel.app/?path=/docs/components): 26 component families, public.
- [Latest updates](https://www.kraken.tech/product-updates): Periodic product roundup (no versions, no dates).
- [Marketplace](https://www.kraken.tech/marketplace): Partner and solution listings, governed by signed access-and-use terms.

## Specs

No OpenAPI, Swagger, AsyncAPI, GraphQL SDL, JSON Schema or Protobuf definition is published by Kraken Technologies anonymously. Probed 2026-07-27: docs.kraken.tech /openapi.json, /swagger.json, /api-docs, /redoc, /graphql all return the SSO login page as text/html; www.kraken.tech returns 404 for the same paths; api.kraken.tech, developer.kraken.tech, data.kraken.tech and mcp.kraken.tech do not resolve in DNS.
